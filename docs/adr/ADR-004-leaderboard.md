# ADR-004 — Shared leaderboard
Status: Proposed
One cross-platform scoreboard over internal players, separate by challenge ID, difficulty and ruleset version. Only verified official attempts count. Stable ranking and ties must be defined. Daily cutoff timezone must be explicit (UTC proposed) and visible to clients. All-time aggregation and offline/race edge cases are NOT YET DECIDED; do not silently choose score totals across unequal difficulty levels. Game Center/Play Games integration optional, not authoritative.
